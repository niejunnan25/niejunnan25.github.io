01 / THE IDEA

Learning from what
happens along the way.

Absolute progress can be hard to label in a failed execution. A missed grasp, a stall, or a recovery can still tell us how progress relates across time.

01

Observe execution events

Use successful, suboptimal and failed trajectories to identify within-trajectory progress relations.

02

Anchor the progress scale

Combine these relations with temporal labels from successful demonstrations.

03

Shape the policy reward

Predict task progress and use it as the potential in reward shaping during reinforcement learning.

INSTALLATION · VERSION 0.2.0

Conda + pip.
Run on your GPU.

Linux x86_64 and an NVIDIA driver reporting CUDA Version ≥ 12.8. Inference needs no CUDA Toolkit. The last two commands install optional fast kernels, recommended for the supplied example predictions.

Use the installation guide for adaptation, compiler requirements and troubleshooting. The SDK is public on GitHub and can be installed with the commands below.

git clone https://github.com/niejunnan25/Event2Reward.git
cd Event2Reward
conda create -n event2reward python=3.10 -y
conda activate event2reward
pip install -e .

# Recommended: the same fast kernels as the paper environment (prebuilt, no compiler needed)
pip install flash-linear-attention==0.5.2 fla-core==0.5.2
pip install https://github.com/Dao-AILab/causal-conv1d/releases/download/v1.7.0/causal_conv1d-1.7.0%2Bcu12torch2.8cxx11abiTRUE-cp310-cp310-linux_x86_64.whl

QUICK START · STAGE2

Predict progress from your observations.

Use the public Stage2 checkpoint with your own observations and an independent successful goal. See the input and inference guide.

BF16, batch 1: about 9 GiB allocated GPU memory and 0.09 s/query. Measurement details ↗

conda activate event2reward
event2reward infer \
  --bundle niejunnan25/Event2Reward-Qwen3.5-4B-Stage2 \
  --observations /path/to/your/observations.json \
  --output prediction.json
Numerical examples and training notes

The recorded LIBERO examples include expected predictions for the suite-adapted models; those values are not expected outputs for Stage2 on your own observations. Stage2 and the four suite models have 40 fixed-input comparisons; Stage1 has separate loading, preprocessing and initialization checks. These do not assign a policy success rate to an individual checkpoint.

Progress may decrease or misjudge an execution. Accelerated adaptation can vary across seeded runs. Trend is an auxiliary output and is not presented as an event detector.

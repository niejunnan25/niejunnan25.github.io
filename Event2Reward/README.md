# Event2Reward project website

Public project URL: https://niejunnan25.github.io/Event2Reward/

Static website prepared for publication on 2026-10-28. The manuscript has 17 authors; Junnan Nie and Zitian Fan are equal contributors and Songfang Huang is the sole corresponding author. The bundled PDF is the 44-page v26 manuscript, with Project Page above Code.

Stage1 and Stage2 are public. The SDK, four suite models, full event annotations and complete RL framework have separate pending releases. The format download contains schemas, documentation and synthetic examples, not the complete paper dataset.

The four displayed LIBERO-Spatial cases preserve 712 recorded predictions. They are qualitative examples from a suite-adapted model, not Stage2 zero-shot evaluations. Source attribution is in assets/demos/NOTICE. Website code is Apache-2.0; paper figures and media retain their respective terms.

Deployment: copy this directory to Event2Reward/ in the existing public niejunnan25/niejunnan25.github.io repository. GitHub Pages serves main at the repository root. Preserve the existing personal homepage. No server-side application or model execution is required.

Event2Reward-Qwen3.5-4B-LIBERO-10

The inference SDK and Stage1/Stage2 weights are public. The four LIBERO suite models are pending public release.

Progress estimation for LIBERO-10, using the reward model adapted for the paper experiments.

Model

Qwen3.5-4B with a 101-bin progress head and a three-class auxiliary trend head. Full BF16 parameters, processor, tokenizer, configuration and training state metadata are included. Install the Event2Reward Python package separately.

Saved at adaptation step 500.

Initialized from Stage2 joint training and adapted with 200 target trajectories from LIBERO-10. Full Stage2 retraining requires the Stage1 checkpoint and additional datasets. See training recipes and data populations.

Use

Follow the Conda + pip installation. Inference needs an NVIDIA driver supporting CUDA 12.8; no CUDA Toolkit is required.

from event2reward import Event2Reward, Observation
model = Event2Reward.from_pretrained("niejunnan25/Event2Reward-Qwen3.5-4B-LIBERO-10")
obs = Observation("place the bowl on the plate", "start.png", "goal.png",
                  [f"h{i}.png" for i in range(5)])
print(model.predict([obs]))

Inputs are task text, episode start, an independent successful goal image, and five causal RGB frames at 0.1-second intervals. Repeat the start frame for early history positions. Never use the evaluated trajectory's final frame as its goal. See the inference guide.

Results and limitations

54.64 ± 8.70% policy success in the complete frozen-policy residual SAC system, averaged over five seeds. This is a system result, not a success rate obtained by running this checkpoint alone.

Progress is a learned estimate in [0, 1], not a calibrated probability of success. It may decrease, underestimate completion, overestimate failures or miss recovery. No general success threshold is supplied. The Spatial demonstration includes both qualitative successes and errors; it is not an aggregate model benchmark.

Trend is an auxiliary training output and is not used in the downstream shaping reward. It is not offered as an event or failure detector. Variance and entropy are uncalibrated distribution statistics. Reproducibility and numerical comparison describe the reference setup and commands.

Installation

The inference SDK and Stage1/Stage2 weights are public. The four LIBERO suite models are pending public release.

Requirements

  • Linux x86_64 and Conda; the commands below select Python 3.10.
  • NVIDIA GPU and driver: nvidia-smi must report CUDA Version ≥ 12.8. This field describes driver compatibility, not an installed compiler.
  • No CUDA Toolkit is required for inference. PyPI's default Linux torch==2.8.0 installs CUDA 12.8 runtime dependencies; no separate PyTorch index is needed.

Inference

git clone https://github.com/niejunnan25/Event2Reward.git
cd Event2Reward
conda create -n event2reward python=3.10 -y
conda activate event2reward
pip install -e .

# Recommended: the same fast kernels as the paper environment (prebuilt, no compiler needed)
pip install flash-linear-attention==0.5.2 fla-core==0.5.2
pip install https://github.com/Dao-AILab/causal-conv1d/releases/download/v1.7.0/causal_conv1d-1.7.0%2Bcu12torch2.8cxx11abiTRUE-cp310-cp310-linux_x86_64.whl

The final two commands are optional acceleration packages. Without them, Transformers uses its PyTorch implementation, which is slower and can change the predictions. Use the recommended kernels when comparing against the included expected predictions. Numerical comparisons are documented in reproducibility.

Without the optional acceleration packages

Without the recommended kernels, Transformers falls back to a PyTorch implementation. It is slower and its outputs differ slightly from the recommended kernels. The table lists the largest absolute differences from the kernel outputs over eight fixed inputs per model; they are observed on these inputs, not error bounds or a measure of task success.

Download a model

Once public access to the model repositories is enabled:

hf download niejunnan25/Event2Reward-Qwen3.5-4B-Stage2 --local-dir checkpoints/stage2

Or load directly:

from event2reward import Event2Reward
model = Event2Reward.from_pretrained("niejunnan25/Event2Reward-Qwen3.5-4B-Stage2")

revision and cache_dir may be passed to from_pretrained. HF_HUB_OFFLINE=1 uses the local Hub cache. Local model directories work with the same API and CLI.

Adaptation

pip install -e ".[train]"

FLA's current checks suggest that non-Hopper GPUs do not need the additional CUDA compiler setup below; adaptation has not yet been tested on a non-Hopper GPU. On Hopper (H100/H200/H20), also install TileLang and provide a CUDA 12.8 compiler:

pip install tilelang==0.1.9 apache-tvm-ffi==0.1.10

The TVM FFI version is pinned because newer releases can fail when TileLang first loads during the backward pass.

Choose one compiler setup:

  1. Existing installation: export CUDA_HOME=/usr/local/cuda-12.8.
  2. User-local installation:

bash python scripts/install_cuda_toolchain.py --prefix ~/cuda-12.8 export CUDA_HOME=~/cuda-12.8

FLA's Hopper backward kernel requires TileLang with the pinned Triton version. This compiler requirement applies to adaptation, not inference. The compiler must be at least CUDA 12.8 and must not exceed the CUDA Version reported by nvidia-smi.

Check your environment

event2reward env
event2reward env --json

This read-only diagnostic always exits with status 0; inspect its final conclusion. Missing optional fast kernels do not prevent inference. Hopper compiler checks concern adaptation, so a missing compiler can still yield ready for inference. The diagnostic and training preflight apply the same Triton-version rule and reject the known incompatible TileLang 0.1.9 / TVM FFI 0.1.15.post0 combination.

Troubleshooting

  • A PyPI mirror can be selected with -i https://mirrors.aliyun.com/pypi/simple/ or -i https://pypi.tuna.tsinghua.edu.cn/simple. For Hugging Face, set HF_ENDPOINT=https://hf-mirror.com before starting Python.
  • If an offline Conda environment has no pip, run python -m ensurepip --upgrade, then python -m pip install --upgrade pip.
  • If GitHub is unreachable, download the official causal-conv1d wheel on another machine and install that file with pip install <downloaded-file.whl>.
  • Create a separate Conda environment: an existing RL environment may require incompatible torch or Transformers versions.
  • Triton JIT compilation needs a C compiler such as gcc.
  • Set PYTHONNOUSERSITE=1 if user-site packages interfere with imports.
  • Stage1 and Stage2 are publicly available. The four LIBERO suite models remain private; a complete local model directory also works.

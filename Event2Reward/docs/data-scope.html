Event2Reward data formats and examples

Input formats, processing-tool documentation, and original synthetic examples for Event2Reward, version 0.2.0. This package does not contain the full event-annotated training dataset.

Included Purpose
Observation schema Task text, episode start, independent successful goal, and five causal history images
Synthetic example Eight queries with geometric images and a separately drawn goal reference
Data formats Inference observations, relation records, supervision masks, and adaptation manifests
Processing tools Generate synthetic training data, relocate media paths, materialize portable indices, and inspect splits

Try the input format

Follow the Conda + pip installation guide, then run from this package's root directory:

event2reward infer --bundle niejunnan25/Event2Reward-Qwen3.5-4B-Stage2 \
  --observations examples/synthetic-inference/observations.json \
  --output synthetic-progress.json --device cuda:0

Stage1 and Stage2 are publicly available on Hugging Face. The inference SDK and four LIBERO suite models remain private until their code and model releases. A complete local model directory can also be passed to --bundle. The geometric images illustrate input wiring; they are not a robot benchmark and do not have expected model scores. See their provenance.

For an executable synthetic adaptation example, use the generator in the code repository:

python -m event2reward.example_data --output data/synthetic

Continue with the adaptation guide. The processing implementations live in the code repository, rather than in this data package.

Scope and terms

The event annotations, training/validation/test splits and source-media references used in the paper are coming soon. Source robot videos, private human-video data and the original annotation-production pipeline are not included. The four LIBERO demonstrations ship with the code repository examples.

The original schema, documentation, and synthetic images use Apache-2.0; see NOTICE. Third-party datasets and models retain their own terms.

Choosing a model

Use Stage2 for general progress estimation or as the starting point for adapting to your own tasks. Stage1 is the pretrained initialization used for Stage2. Stage1 expects five history frames at 0.25-second intervals; Stage2 and the four LIBERO models use 0.1 seconds. The Spatial, Object, Goal, and LIBERO-10 models correspond to the paper's suite-specific experiments.

The reported policy success rates belong to the complete RL system with adapted reward models. They are not standalone checkpoint accuracy. Progress is a learned estimate, not a calibrated success probability; trend is an auxiliary output.

Data and media

The data package describes formats and the available processing utilities. It does not contain the complete event annotations, training indices, private human-video corpus, or original annotation-production pipeline. These materials require a separate release decision. Upstream code licenses do not automatically grant permission to redistribute all dataset and simulator assets.

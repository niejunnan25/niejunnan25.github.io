Data formats and tools

Stage1 and Stage2 weights are public. The inference SDK and four LIBERO suite models are not yet public; SDK commands require code repository access.

This repository supplies data schemas, relation-aware sampling and collation, split inspection and path relocation tools, plus an original synthetic example. Four selected LIBERO videos are included for qualitative use; see examples for attribution. The event annotations, data splits and source-media references used in the paper are coming soon. Third-party training videos and the private human-video pretraining corpus are not included.

Relation records

Each JSONL row contains clips and an optional relation. A clip identifies sample_id, dataset_id, physical_episode_id, task instruction, video_path, start_frame, goal_frame, five history_frames, current_frame, and its supervision masks. Independent goals use goal_dataset_id and goal_video_path. target_progress is in [0,1]; progress_valid controls absolute progress supervision. target_trend is 0/1/2 (growth/stable/regression), with a separate trend_valid mask.

A relation specifies kind, anchor_index, secondary_anchor_index when needed, member_indices, and margin. Kind 3 constrains a recoverable event to be no higher than its anchor; kind 4 places an irrecoverable event strictly below its anchor; kind 5 is a hesitation plateau; kind 6 is a regression valley between two anchors. Preserve the annotation's anchor semantics and uncertain boundaries; source annotations are not universally human-verified. The executable schemas and loss definitions are the authority for each relation's inequality.

Generate complete records and an adaptation manifest:

python -m event2reward.example_data --output data/synthetic

See adaptation for source fractions and supervision masks.

Portable indices

event2reward-data exposes materialize, materialize-set, and inspect-splits; use --help for each command. Portable indices reference asset:// IDs and need an asset map to local media. These utilities do not download licensed source videos.

event2reward-data materialize --index portable.jsonl.gz --asset-map local-assets.json --output materialized.jsonl
event2reward-data inspect-splits --indices train.jsonl val.jsonl test.jsonl --output splits.json

The split checker examines declared physical episode identities and goal-source splits. Missing identity evidence is reported; different IDs do not prove different video content. Preserve source identifiers and split assignments throughout processing. Existing output files are protected from overwriting.

For recognized absolute media paths, event2reward-train rebase-index --input original.jsonl --output relocated.jsonl --mapping paths.json relocates paths without changing labels or task text. The mapping is a JSON object from each old media root to a new absolute root.

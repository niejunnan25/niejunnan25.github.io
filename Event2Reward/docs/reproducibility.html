Numerical comparison

pip install -e ".[examples]"
event2reward infer --bundle checkpoints/spatial --observations examples/quickstart/observations.json --output prediction.json
python examples/libero_spatial/run_example.py --bundle checkpoints/spatial --check

The video command compares all supplied output fields against the included expected predictions with absolute tolerance 1e-5, relative tolerance zero. The quick-start reference is examples/quickstart/expected_output.json. Preprocessing must use the supplied lossless images and the video's fixed timestamp/RGB conversion.

Resource use (BF16/SDPA, batch 1; timings include preprocessing and exclude decoding and plotting): on H20D, the four video examples (712 queries) take 0.0867 seconds/query with 8.68 GiB peak allocated memory (8.81 GiB reserved), and loading with integrity checking takes about 21 seconds. On H200, a single fixed Stage2 query takes a median of 0.0903 seconds over 30 timed queries after 5 warm-up queries, with 8.68 GiB peak allocated memory and about 13 seconds to load. Allocated memory is not a minimum hardware requirement.

With the reference environment and the recommended kernels, the quick-start CLI reproduces examples/quickstart/expected_output.json and the video command reproduces all 712 supplied predictions.

The synthetic example in the adaptation guide runs four optimizer steps with seed 42 while keeping the 500-step schedule. The parameters update, and the resulting model exports, reloads and predicts. Accelerated adaptation is not bitwise reproducible, so losses differ slightly between runs. The example demonstrates execution and parameter updates, not training convergence.

Without the optional acceleration packages

Without the recommended kernels, Transformers falls back to a PyTorch implementation. It is slower and its outputs differ slightly from the recommended kernels. Paper protocol and populations

LIBERO uses frozen-base-policy residual SAC with adapted reward models, 200 target trajectories per suite, and five independent seeds. Each seed averages ten tasks with equal weight; reported values are the mean and sample standard deviation across seeds. Budgets are 200k environment steps for Spatial/Object/Goal and 1.2M for LIBERO-10. Results use the last scheduled independent evaluation within the budget. The eight plotted tasks are selected examples, not the full benchmark.

Real-robot comparisons match a 30-minute training budget, with three independent runs per task/condition, 20 evaluation episodes per checkpoint, and equal weighting over three tasks for each system. The additional single-run plug-insertion timing example is not evidence of a universal speedup.

Pretraining replay is additional. These are configured trajectory populations, not a count of visits before step 10,000. The paper's real-world table and the additional simulation population use distinct scopes. Full pretraining and joint training require source datasets and replay data outside this release. Stage2 starts from the Stage1 checkpoint listed in the Model Zoo; users can adapt Stage2 using their own trajectories.

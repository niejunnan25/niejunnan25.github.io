Event2Reward 0.2.0 · Project documentation

Inference

Stage1 and Stage2 weights are public. The inference SDK and four LIBERO suite models are not yet public; SDK commands require code repository access.

Input and output

Each Observation contains task text, the episode start image, an independent successful goal image for the same task, and exactly five causal history frames in chronological order. Supply PIL images, RGB arrays, or image paths. Images are center-cropped and resized to 224 × 224. Use an external camera consistently; the examples do not use the wrist camera.

For Stage2 and the four LIBERO models, sample observations at 10 Hz. For query index q, use [max(0, q-4), ..., q]: early histories repeat the first frame. Never use future observations or substitute the evaluated video's final frame for the independent goal.

progress is the expectation over 101 progress bins in [0, 1]. It is not a success probability, can decrease, and may underestimate a completed task or overestimate a failed one. Outputs also contain progress variance/entropy and auxiliary trend probabilities in growth, stable, regression order. No universal success threshold is supplied.

Stage1 is primarily an initialization checkpoint and uses a 0.25-second training history interval; see training stages. The released loader always center-crops. Stage1 training instead squared frames per source dataset (center crop, letterbox, or a fixed crop), so to match its training inputs, square non-square camera frames before passing them in.

Single and batch prediction

from event2reward import Event2Reward, Observation
model = Event2Reward.from_pretrained("niejunnan25/Event2Reward-Qwen3.5-4B-Stage2")
observation = Observation("place the bowl on the plate", "start.png", "goal.png",
                          [f"h{i}.png" for i in range(5)])
result = model.predict([observation], include_distribution=True)
batch_result = model.predict([observation, observation])

Batching requires additional memory. include_distribution=True adds the full 101-bin probability vector. model.prepare(observations) exposes the model inputs for numerical comparisons.

Trajectories and MP4

results = model.predict_trajectory(
    frames=frames, task="place the bowl on the plate", goal="goal.png",
    batch_size=1, stride=1, timestamps=timestamps,
)

frames must already be sampled at the observation interval; timestamps are strictly increasing seconds, with one timestamp per frame. Optional query_indices selects queries without changing the history. Each result includes its query/history indices and timestamp. The video example handles MP4 decoding using presentation timestamps and a fixed RGB conversion.

CLI

event2reward infer --bundle niejunnan25/Event2Reward-Qwen3.5-4B-LIBERO-Spatial --observations examples/quickstart/observations.json --output prediction.json

The observations JSON is a list of objects with task, start, goal, and history. Image paths resolve relative to that JSON file. --bundle also accepts a local model directory; --device defaults to cuda:0.

Save and export

model.save_pretrained("checkpoints/saved-copy")
reloaded = Event2Reward.from_pretrained("checkpoints/saved-copy")

The destination must not exist. This saves the current parameters and loading assets. After adaptation, export a checkpoint through event2reward export; its --help lists the checkpoint, backbone, output, model identifier, and integrity argument. Supply the same backbone/tokenizer used for training. Training export and reload are distinct from resuming optimizer state.
